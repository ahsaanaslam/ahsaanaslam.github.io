# Project documentation (PDF)

Put **approved, sanitized** PDF documentation for your ERP modules here, e.g.:

- `operations-management.pdf`
- `hr-payroll.pdf`
- `material-master.pdf`

Then link them from the "Documentation" part of each project's detail panel in
`index.html` — replace the placeholder paragraph with:

```html
<p><a href="assets/docs/operations-management.pdf" target="_blank" rel="noopener">View documentation (PDF)</a></p>
```

**Important:** only publish documentation your company has approved for public
sharing, with all confidential information removed.
