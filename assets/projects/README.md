# Project screenshots

Put **approved, sanitized** screenshots of your ERP modules and websites here.

Suggested names (the HTML comments in `index.html` reference these):

- `operations.png` — Operations Management module
- `hr.png` — HR & Payroll module
- `material-master.png` — Material Master module
- `shopify.png`, `wordpress.png`, `restaurant.png`, `ecommerce.png` — web projects

**Important:** never upload screenshots that show real employee data, internal
company data, credentials, or database structures. Blur or crop anything
sensitive, and get company approval before publishing.

To use a screenshot, open `index.html`, find the matching
`<!-- Replace with an approved screenshot ... -->` comment inside the project
card, and swap the placeholder block for the `<img>` tag shown in that comment.
